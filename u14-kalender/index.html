Kalender abonneren op je gsm

Zet deze kalender op je eigen telefoon zodat alle wedstrijden en taken automatisch verschijnen — ook wijzigingen.

iPhone / iPad
Android

Snelste manier:

Abonneer op iPhone

Tik de knop op je iPhone → iOS vraagt te abonneren → 'Toevoegen'

Handmatig (als de knop niet werkt):

  1. Open Instellingen → Agenda → Accounts → Voeg account toe → Overige
  2. Kies Voeg agenda-abonnement toe
  3. Plak deze URL:
webcal://p147-caldav.icloud.com/published/2/MTA0NzQyMjYxNTAxMDQ3NKgGFFnPaC3DjyRnKTXOPIVsNQoVeJsqiBPs_0ciz1bo7W3tsSaJvNS8RzLT-Nx9-ZvwF9nHnS_QPvqU4yiNnKY

Via Google Calendar (aanbevolen):

  1. Ga in je browser naar calendar.google.com (werkt niet in de app, wel op mobiel via browser)
  2. Links onder "Andere agenda's" klik op +
  3. Kies Van URL
  4. Plak deze URL:
https://p147-caldav.icloud.com/published/2/MTA0NzQyMjYxNTAxMDQ3NKgGFFnPaC3DjyRnKTXOPIVsNQoVeJsqiBPs_0ciz1bo7W3tsSaJvNS8RzLT-Nx9-ZvwF9nHnS_QPvqU4yiNnKY

Alternatief via app: installeer ICSx⁵ uit Play Store → tik + → plak dezelfde URL

Na toevoegen: de kalender verschijnt in je Google agenda op alle apparaten (ook je Android telefoon).
